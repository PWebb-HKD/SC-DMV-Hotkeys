Try the extension without a DMV account

The practice portal and fictional reports are packaged inside the extension. No server, Node installation, external download or real driver record is needed. Demo Mode uses the shared command, navigation, parsing, status, queue and barcode workflows.

Start here

  1. On first install, review the bundled EULA, check the agreement box and accept. If you closed or declined it, open the toolbar → About → Open EULA / Review acceptance. Functions remain disabled until agreement.
  2. Open the extension toolbar popup and select Settings → Practice environment → Demo Mode.
  3. Enable Plate & license status alerts and, beneath it, Show driver photo and name. Voice alerts are optional.
  4. Select Open practice portal. Keep Demo Mode enabled throughout this walkthrough.
  5. In the extension's Recent searches tab, select DL # Search and enter 100000101. The extension fills the fixed demo/demo account automatically and opens a fictional report and a labeled valid-license alert.

The normal quick-action buttons work without keyboard setup. To test hotkeys, open Keybinds → Set up your shortcuts, assign Open Shortcut Menu to Alt+H in Chrome's extension shortcut settings, then choose commands from that menu. Chrome must remain running for global hotkeys.

Follow-ups from an open report

  • Barcode: run Barcode from the selected vehicle or driver PDF. Inspect the labeled fields, choose Edit Data, make a correction and confirm invalid input hides the barcode. The barcode is for the fictional data shown.
  • Same address: run DL 100000101, then Same address from that PDF. Collect Customer/Owner Numbers retains all three customers and starts with the second. Next/Previous move through the extension's queue.
  • SCUTTIES: from the Avery driver PDF, select SCUTTIES. It fills EXAMPLE and 01/02/2000 and submits Search. Three citations are listed; View opens the corresponding read-only details. A compound surname and a no-results sample are also available in the portal.

Viewer and background searches

New PDF results use the bundled viewer in both light and dark mode. Test its color toggle, continuous scrolling, selectable text and Print. Print opens the exact original PDF in Chrome's native viewer. Photo pixels retain their colors.

With status popups enabled, enable Run record searches in the background. The owned query window starts minimized; a report and status popup appear when ready. A subsequent background search reuses its owned results tab. Same-address results are revealed, and SCUTTIES stays in the foreground. You can restore the query window manually.

Recovery and separation

For controlled failures, turn background search off and choose Demo test controls in the existing practice transaction tab before the next extension search. Try expiration, a delay, a technical timeout or an unavailable report. Packaged failures simulate these states locally; they are not HTTP outages. A technical timeout does not advance the extension queue. Each valid attempt consumes its selected fault once.

The site's manual queue buttons and the extension's queue are separate. Use the extension commands above to verify its worker behavior. The standalone site's preview buttons are omitted here; automatic alerts come from the extension itself.

Demo history, queue, report snapshots and session-only blacklist are separate from the live vault. Alert and appearance preferences are shared. Switching Demo Mode off cancels ongoing work and returns to live routing. A focused report from the other environment cannot supply a follow-up.

Live access and review scope

Live operation requires an authorized SCDMV account. No approved live test account is available. This disclosed synthetic mode is available to every user and does not provide real government records. It does not establish the availability of the live service or grant access to it.

Use Chrome 140 or newer. Live searches require the declared SCDMV host permission. The bundled demo requires no localhost permission. No real credentials should be entered into the practice portal.
