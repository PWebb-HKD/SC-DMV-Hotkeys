Set up your shortcuts

Open the keyboard shortcut settings below and find SC DMV Hotkeys. Click the edit icon or shortcut box for each command, then press your preferred key combination using a modifier such as Alt or Ctrl. For each search shortcut, change the Scope setting from In Chrome to Global so it works while another application is focused or the browser is minimized. The browser must remain running.
