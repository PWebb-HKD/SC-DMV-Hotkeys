Set up your shortcuts

For a simple setup, assign only Open Shortcut Menu to Alt+H and leave other commands unassigned. Optionally assign individual functions to the recommended keys in the setup guide or to keys of your choice. Open the keyboard shortcut settings below and find SC DMV Hotkeys. Click the edit icon or shortcut box for each command, then press your preferred key combination using a modifier such as Alt or Ctrl. For each shortcut you assign, change the Scope setting from In Chrome to Global so it works while another application is focused or the browser is minimized. The browser must remain running.
