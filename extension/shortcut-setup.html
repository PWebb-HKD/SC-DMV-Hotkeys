SC DMV Hotkeys

Enable shortcuts outside the browser

Shortcuts start unassigned on a fresh installation. Assign all ten commands below and set their scope to Global to use them while another app is focused or the browser is minimized.

  1. Open browser keyboard shortcut settings and find SC DMV Hotkeys.
  2. For each unassigned command, click its shortcut box or edit icon and press the preferred combination below, or choose your own.
  3. For each command listed below, set Scope to Global. If it shows In Chrome (or In browser), change it to Global; if it already shows Global, leave it there.
  4. Keep the browser running. Global shortcuts can then work while it is minimized or another app has focus.

A shortcut already in use may remain unassigned. Choose an available combination. If your browser does not offer Global scope, shortcuts work only while that browser is focused. Global shortcut availability depends on your browser and operating system.

Alt+Minus is recommended for Pause/Resume Shortcut Actions. Pausing stops shortcut actions but Chromium may still reserve Global keys. Unassign conflicting keys in browser settings to release them to another program.
