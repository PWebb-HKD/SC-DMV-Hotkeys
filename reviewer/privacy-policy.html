SC DMV Hotkeys privacy policy

Prepared for version 1.8.44. Publisher/owner: Preston Webb.

Purpose and information processed

The extension helps authorized users perform SCDMV member searches and review related reports. It processes user-entered login credentials and query identifiers, report text and available photographs, names/addresses and vehicle/license/violation information as needed for those workflows. It can derive status summaries, queues and PDF417 data-entry barcodes. This information may be sensitive even when processing happens locally.

Where information goes

User-requested live searches send the necessary login/query to SCDMV through its website. The extension does not implement developer-operated analytics, advertising, data-sale/sharing endpoints or an external report-storage service. Report parsing, image extraction, barcode generation and preference handling occur in the browser using packaged code. Voice announcements use packaged recordings or voices Chrome reports as local.

Storage and retention

Preferences use browser local storage. If the user chooses to save login information, credentials and blacklist entries are stored in an encrypted local vault protected by the user's passphrase. Unlocked credentials/key material, search history, customer queues and cached report text/photos are held in trusted browser-session storage. Session data is not stored through Chrome sync and is cleared by the browser when that session ends; the extension also removes snapshots as tracked tabs close and provides history/queue/private-state clearing controls. The encrypted vault and preferences remain until removed by the user or extension removal. Browser/OS profile management can affect retention outside the extension's own code.

Practice mode

The bundled practice environment contains invented records and procedural images, requires no live account/server and uses separate demo history, queue, report and blacklist state. It does not query SCDMV while running demo searches. Alert/appearance/shortcut preferences remain shared between modes. Do not enter real credentials or private records into the practice examples.

Controls and security

Users can disable voice/status/background features, switch environments, clear session history/queues and explicitly delete saved user information and the encrypted vault. Deleting the vault also removes its blacklist protection until entries are re-established. The extension restricts private storage to trusted extension contexts, binds report captures to their source documents and limits live website access to the declared SCDMV hostname. No software can promise absolute security.

Contact and changes

Before publication, the publisher must supply a monitored support email or webpage here and in the store listing. Do not send real credentials, reports, signing keys or session cookies through public support channels. This policy should be updated when the extension's handling of information changes.
